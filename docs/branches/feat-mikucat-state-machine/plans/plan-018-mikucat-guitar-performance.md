## Goal

将固定参数往返替换为可长期播放的手部演奏动画机：有动作语汇、乐句、强弱起伏及连续衔接。
首版采用已向用户说明的“轻松随性、偶尔加强”试调风格，实际自然程度仍由 Windows dev 验收。

## Scope

- 7 类手部片段与 10 个乐句，数据与播放器分离；手部写 `ParamMouseX/Y`，不改素材。
- 用户追加头身联动试调：利用现有 `ParamAngleX/Y`，按乐句安排停稳、微动、换重心及抬起/下压/
  回收曲线；不新增模型通道，也不做整模画布变换。
- 轻奏/常奏/强调/放松四种内部模式，句边界选择、近期防重复、强调冷却；段内保持节拍。
- 随机选择只发生在句边界，可注入固定随机源复现；不增加每帧噪声、音乐或外部依赖。
- 从当前头手姿态进入；过渡继承位置与速度；退出在短收势内交还鼠标，快速重入取消旧退出。
- 被接管时只缓存鼠标目标、不写模型；销毁直接解除 Ticker，不污染下一个模型。
- 继续使用现有表情入口；不增加编辑器或设置界面，不改 Rust、头发物理或 Agent 链路。

## Acceptance

- 连续观察能看到轻拨、扫弦、连拨、强调和收势，有节奏而非每帧随机；不会固定周期复读。
- 乐句之间不跳回零点，暂停不冻结在任意中途姿态；重复点击吉他不会重启/重复订阅。
- 退出无需等待乐句结束；快速退出/重入及切换模型后，无旧循环或旧鼠标结果抢写。
- 数值测试保证范围、连续性、帧率一致性与长期调度规则；不把这些测试当作视觉验收。
- 活跃乐句保留换重心和明显的正负 Y 姿态，轻奏/放松允许头身停稳或微动而手部继续演奏；
  不再要求每句都大幅左右摆动。头身曲线不被短手部动作/休止重启，退出恢复鼠标头手目标。
- 重音有抬头蓄势、贴近扫弦落点的短促下压、短暂承重和较慢回收；常奏按乐句分轻重，
  不把所有碎拨或普通扫弦都变成同样的大点头。相对琴身的位置与动静对比仍由视觉验收。

## Risks / Dependencies

- 双手与琴身仍由两轴共同驱动；动画机不增加模型没有的独立指法或换把能力。
- 头身 AngleX/Y 会带动衣领、上衣和裙子，但不会带动吉他/双手；幅度过大会显得脱节。
- 现有模型没有独立 BodyAngle 或 AngleZ；脸部/眨眼不改，不直接编排头发物理输出通道。
- easy-live2d 0.4.4 在物理计算之后应用外部参数覆盖，头发惯性未与新点头/摇头保证同步。
  不能仅凭本版头发表现就断定必须增加变形通道，需先区分模型能力与运行时物理输入顺序。
- Windows dev/编译由用户执行；本步不操作 Git 写命令，不改仓库外 agent 配置。

## Implementation / Tuning

- `guitarPerformance.ts`：7 类动作关键帧、10 个乐句、各模式速度/力度/停留句数及强调冷却；
  每个乐句的 `head` 为整句归一化头身轨迹，`GUITAR_HEAD` 控制参数幅度：左 28、右 26、
  抬起 24、下压 28；力度权重下限 0.85，不再叠乘单次拨弦强度或随机手部偏置。
  上述是幅度上限而非每句必达目标，轻奏/放松用小姿态和保持段，常奏按句分轻重；重音下压
  0.4 拍、落点比手部重扫晚 0.06 拍，随后保持 0.16 拍再慢回收。
- `guitarHandAnimation.ts`：进入/演奏/退出生命周期与乐句调度，段间承接位置、速度；每帧只写
  两个手部和两个头身通道。头部沿整句时长推进，短拨弦/休止不打断该轨迹；手部曲线保持不变。
  内部轻奏/常奏/强调/放松模式与 Agent WORK/WAIT/DONE 无关。
- 普通退出为 240 ms，目标追踪缓存的鼠标位置但不延长退出期限；销毁直接解除回调。
  头手一起交接，仍非独立身体动画或完整头发物理解算改造。
- 鼠标禁用期间允许计算并缓存目标，不应用到模型；代次检查继续拒绝跨表情/模型的旧异步结果。
- 每帧时间上限 100 ms，恢复渲染时不追赶长时间积压；正常 30/60 FPS 使用相同时间轴。
